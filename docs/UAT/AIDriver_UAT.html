1. Purpose

This document is the script for teachers and students to confirm that the AIDriver kit works as intended in a real classroom before it is released to classes. It covers the changes delivered in this release:

  • Custom firmware: updated to the latest MicroPython, a more thorough GP4 recovery mode, and a firmware version number.
  • Upload to robot: the new Robot toolbar in the simulator’s code editor. It lets students connect a robot over USB, upload code to main.py, run it, view its logs and stop it. It also checks the robot’s firmware and sends students to their teacher if it is missing or out of date.
  • Simulator fixes: speed slider, live step mode, steering direction, challenge success messages, speed checks that match the robot, the maze challenge, code checks and saving, and a bigger Challenge 0 debugging exercise (9 bugs).

Automated tests (446 Jest tests and the Python tests) already pass for this build. UAT checks what automated tests can’t: real robots, real browsers and Chromebooks, and whether the kit makes sense to students and teachers.

4. Test environment and preparation

Computers(a) Windows or Mac computer with Google Chrome or Microsoft Edge (current version); (b) a school Chromebook; (c) any computer with Firefox or Safari (for UT-T01 only).
RobotsRobot A: flashed with the new firmware (UT-F01). Robot B: still on older AIDriver firmware (flashed before this release), if available. Robot C (or a bare Pico): stock MicroPython from Downloads → RP2040 Firmware.
Cables and partsUSB data cable (not charge-only), a jumper wire for GP4 recovery, charged robot battery pack.
Other softwareArduino MicroPython Lab (for UT-C04 and to inspect files on the robot).
SpaceA clear floor area of at least 2 m × 2 m for driving tests.
Test programsAppendix A. Type or paste them into the simulator’s code editor when a step says “Program A1” etc.
Safety: the motors run from the robot’s battery pack. Keep the battery switch off while the robot is plugged into a computer (the toolbar relies on this; see UT-U05). Only switch it on after unplugging the USB cable, with the robot on the floor.

How to record results

  • Run the steps in order. Tick Pass only if everything in “Expected result” happens.
  • On a failure, tick Fail, write what happened in Notes, and add a row to the defect log (section 7) with the test ID. Screenshots of the debug panel help the developer.
  • Where a test is run on both a computer and a Chromebook, note which one(s) in Notes (e.g. “Chrome ✓, CB ✓”).
  • Tests marked Critical must pass for release (see section 8).

8. Acceptance criteria

The release is accepted when:

  1. Every test marked Critical passes on a computer (Chrome or Edge) and a school Chromebook.
  2. There are no open High severity defects.
  3. At least 90% of all tests pass, and every remaining Medium or Low defect has an agreed workaround or fix date.
  4. Student testers can upload and run code using only the Challenge 1 instructions (UT-D01).

Appendix A. Test programs

Type or paste into the simulator’s code editor. Keep the robot’s battery off while it is plugged in.

A1 – Drive forward (UT-U01, UT-U02)

from aidriver import AIDriver, hold_state

my_robot = AIDriver()
my_robot.drive_forward(200, 200)
hold_state(2)
my_robot.brake()

A2 – Print output (UT-U03)

from aidriver import hold_state

for i in range(1, 6):
    print("count", i)
    hold_state(1)

A3 – Syntax error on line 3: missing colon (UT-U04)

from aidriver import AIDriver
my_robot = AIDriver()
if my_robot
    my_robot.brake()

A4 – Simulator-only warning (UT-U05)

from aidriver import AIDriver
import machine

print("frequency", machine.freq())
my_robot = AIDriver()
my_robot.brake()

A5 – Runs until stopped (UT-U06, UT-L04, UT-S01)

from aidriver import hold_state

n = 0
while True:
    n = n + 1
    print("still running", n)
    hold_state(1)

A6 – Ignores Stop (UT-S02). Only use on a robot you can recover with GP4.

while True:
    try:
        while True:
            pass
    except KeyboardInterrupt:
        pass

A7 – Curve with the left wheel faster (UT-M05). Speeds are (right, left).

from aidriver import AIDriver, hold_state

my_robot = AIDriver()
my_robot.drive_forward(120, 220)
hold_state(3)
my_robot.brake()

A8 – Speed checks (UT-M08). Use one of the three marked lines at a time.

from aidriver import AIDriver, hold_state

my_robot = AIDriver()
my_robot.drive_forward(300, 300)       # 1: warning, barely moves
# my_robot.drive_forward(-50, -50)     # 2: ValueError
# my_robot.drive_forward("fast", 200)  # 3: TypeError
hold_state(1)
my_robot.brake()
